Myanmar Calendar


Contribute

Contribute chronicle events from stone inscriptions, bells, and other historical sources to the JSON file below. Each event is a JSON object placed inside the array, and the array must be kept in non-decreasing jdn (Julian Day Number) order since ceMmChronicle.hSearch() looks up events using binary search.

Chronicle Events JSON

To add an event: fork the repository, add your entry in the correct position by jdn, then run python3 util/check-chronicle.py from the repository root to confirm the ordering is valid before submitting a pull request.

Meaning of Each Field


Field Meaning
jdn Julian Day Number of the event, used as the sort key and search key.
my Myanmar year corresponding to the date.
mm Myanmar month name corresponding to the date.
mp Moon phase (Waxing, Full moon, Waning, or New moon).
fd Fortnight day, from 1 to 15.
dow Day of the week corresponding to the date.
desc Short one-line description of the event, shown in the calendar when a matching date is selected.
fullText Optional longer excerpt or transcription related to the event, such as inscription text. Leave as an empty string if not available.
images Optional array of image file names related to the event. Leave as an empty array if not available.

Example entry:
{
  "jdn": 2150320,
  "my": 537,
  "mm": "Kason",
  "mp": "Waxing",
  "fd": 10,
  "dow": "Friday",
  "desc": "Foundation of a monastery, land and servants donated.",
  "fullText": "",
  "images": []
}
